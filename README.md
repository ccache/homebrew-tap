# Ccache Tap

## How do I install these formulae?

`brew install ccache/tap/<formula>`

Or `brew tap ccache/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "ccache/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
